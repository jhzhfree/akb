1. 执行摘要

基础能力必须追平

Parser、Chunk、Embedding、BM25、Vector、Hybrid、Rerank、Query Rewrite、Citation、Retrieval Test 已逐渐成为行业基线。

产品差异重点

Knowledge Card、Assertion、Evidence、Lineage、Derivation、Conflict、Adjudication，把“文档检索”升级为“可信知识生产与治理”。

未来技术壁垒

Ontology、Knowledge Graph、GraphRAG、Query Planner、Query Decomposition、Agentic Retrieval，面向 Agent 的知识基础设施。

UI 研究说明：下文“UI布局规划”分为两部分：①官方公开产品结构能够确认的导航/工作流；②基于公开能力推导的产品布局抽象。后者用于产品设计借鉴，不声称是竞品当前页面的逐像素复刻。

3. 竞品 UI 布局模式归纳

A. 搜索中心型

代表：Glean、Coveo、Google。首页把搜索框/Assistant 放到视觉中心，知识来源、引用和动作围绕结果展开。

适合知识消费者

B. 资源管理型

代表：Microsoft、AWS、阿里百炼。左侧资源导航，中间资源列表/配置，强调 Source → Index → KB → Test。

适合平台管理员

C. 数据集工作台型

代表：RAGFlow。围绕 Dataset，把配置、文件、Chunk、Retrieval Test、Graph 集中在一个工作台内。

最适合我们MVP

D. AI应用构建型

代表：FastGPT、Dify、MaxKB。应用/知识库/Workflow 并列，画布和调试区是核心。

适合Agent应用层

E. Search DevTools 型

代表：Elastic。索引、查询、相关性、向量和开发工具导向，强调工程调试。

适合检索中心

我们的组合

管理侧采用 C+B；消费侧采用 A；Agent 应用层采用 D；检索调试借鉴 E。

推荐

19. MVP 页面规划与优先级

页面优先级核心布局主要参考我们的差异
1. 工作台P0KPI + 待办 + 流水线状态 + 质量云控制台 / GleanTrusted Knowledge Coverage
2. 知识空间列表P0卡片/表格 + 健康度RAGFlow / FastGPT知识资产数量与质量

4. 文档管理P0列表 + 解析/索引状态RAGFlow版本、血缘
5. 文档解析工作台P0原文双栏 + Parsed StructureRAGFlow / AWS人工修正后再生产知识
6. Chunk 管理P0Chunk list + metadata + editRAGFlow / 阿里百炼关联 Card/Assertion

20. 最终“抄作业”清单：借什么，不借什么

Glean

借：统一搜索、ACL、People/Content/Activity 企业上下文。
不借：把搜索首页当知识工程后台。

Microsoft

借：Knowledge Source、Knowledge Base、Query Plan、Execution Details。
不借：Azure 资源层级的复杂度。

AWS

借：Ingestion Job、Smart Parsing、GraphRAG、Observability。
不借：云资源配置式交互。

RAGFlow

借：Dataset Workspace、解析可干预、Retrieval Test。
不借：把 Chunk 当最终知识对象。

FastGPT / Dify / MaxKB

借：低门槛应用/Workflow、简洁导航、私有化体验。
不借：让 Agent Builder 成为知识平台的核心。

火山

借：主体建模、Entity-centric、知识图谱。
不借：为了“有图谱”而提前做复杂图 UI。

Elastic

借：BM25/Vector/RRF 的工程化与调试思路。
不借：把 Query DSL 直接暴露给业务用户。

阿里百炼

借：建库向导、智能切片、Chunk可视化、Hit Test。
不借：只把知识库作为模型应用的附属数据。

我们的核心

必须自己建立：Knowledge Card + Assertion + Evidence + Lineage + Derivation + Conflict + Adjudication。

最终产品 UI 原则：“RAG 参数”不是一级产品心智；一级心智应是 知识概览（资产与健康度）、知识生成（生产与治理）、知识检索（检索与图谱）、接口服务（API / MCP / SSE）、系统配置（平台参数）。技术参数进入高级配置和检索调试页。
已落地形态（对齐当前实现）：一级入口收敛为上述五个，左侧按业务域分组展示——工作台（知识概览）、知识库（知识生成 / 知识检索）、系统集成（接口服务）；系统配置属于低频平台配置，收在侧栏底部工具区的设置图标。下面 19 章的页面规划表按“能力”排列，实际交付时这些能力分别落在对应一级菜单的页面 Tab 内，而不是各自成为一级入口。
