## V1.1 Elasticsearch + Milvus 双检索引擎改造报告

### 1. 目标

将 V1.1 的 JSON + Python BM25/Vector fallback 升级为：

```text
MySQL authoritative state
        │
        ├── Elasticsearch 3.7.0 -> BM25 / exact / Card / Claim lexical recall
        ├── Milvus 1.19.1   -> dense vector recall
        └── Neo4j 5.26      -> graph recall
                    │
                    v
               Weighted RRF
                    │
                    v
                 Reranker
                    │
                    v
             Context Assembly
                    │
                    v
                   LLM
```

JSON IndexStore 继续保留为 fallback / RC / recovery view，不再承担中大规模生产主检索职责。

### 2. 已落地代码

- `ai-service/app/services/retrieval/external.py`
  - `ElasticsearchProvider`
  - `MilvusProvider`
  - REST 长连接复用
  - 索引/Collection 自动初始化
  - Bulk Upsert
  - 查询过滤
  - Document delete
  - capability/status
- `HybridRetriever`
  - BM25/Card/Claim 优先 Elasticsearch
  - Vector 优先 Milvus
  - Graph 继续 Neo4j
  - 外部异常按配置 fallback local
- `KnowledgeIndexer`
  - 新 Chunk/Card/Claim 双写外部检索视图
  - 删除同步
  - rebuild external index
- API
  - `POST /ai/index/rebuild/{knowledgeBaseId}`
  - `GET /ai/retrieval/capabilities`
- Trace
  - `trace.retrievalProviders` 显示各 channel 实际命中的 provider
- Docker
  - Elasticsearch 3.7.0
  - Milvus 1.19.1
  - Neo4j 5.26
- CI
  - Elasticsearch sysctl
  - full-stack dual retrieval E2E assertion

### 3. 检索模式

#### local
只使用 JSON/Python fallback。

#### auto（默认）
优先 Elasticsearch/Milvus；外部异常时回退 local。

#### external / dual
使用外部检索路径；若 `RETRIEVAL_EXTERNAL_REQUIRED=true`，外部失败直接报错，适合生产发现索引服务故障。

### 4. 权限过滤

权限必须发生在 Top-K 之前：

- Elasticsearch：`knowledge_base_id + object_type + permission_tags` Bool Filter
- Milvus：payload Filter，public 数据由 `is_empty(permission_tags)` 匹配

禁止：先召回敏感知识 -> Context 前再过滤。

### 5. 一致性模型

V1.1：

```text
业务写入
  -> MySQL
  -> Local fallback
  -> Elasticsearch
  -> Milvus
  -> Neo4j
```

外部索引均为可重建 view。

V1.2 推荐升级：

```text
MySQL Transaction
     +
Transactional Outbox
       ↓
Index Worker / CDC
       ├── Elasticsearch
       ├── Milvus
       └── Neo4j
```

避免数据库事务等待检索基础设施，并提供 retry / dead-letter / replay / version ordering。

### 6. 重建

```bash
python scripts/reindex-external.py --kb 1
```

用于将 V1.1 Local Retrieval View 重放到 Elasticsearch/Milvus。

后续应改为从 MySQL authoritative objects + evidence 重建，而非依赖 JSON。

### 7. 生产安全

开发 Compose 关闭 Elasticsearch Security Plugin，仅限本地开发。
生产模板启用 Elasticsearch Security，并支持：

- `ELASTICSEARCH_USERNAME/PASSWORD`
- HTTPS
- `ELASTICSEARCH_VERIFY_SSL`
- Milvus API Key

生产环境还应使用正式 CA 和 Secret Manager，不应提交明文密码。

### 8. 当前验证

本环境已完成：

- Python syntax
- V1.1 pipeline
- governance
- adjudication
- API contract
- performance regression
- Elasticsearch Mock REST contract
- Milvus 1.19 `/points/query` Mock REST contract
- DB/Flyway/Mapper contract
- config/index/code-quality gates
- Compose YAML parsing

当前环境没有 Docker，因此真实 Elasticsearch/Milvus 容器联调未在此执行。
CI E2E 已配置为：启动 full stack -> 上传知识 -> 查询 -> 强制断言 `retrievalProviders` 同时包含 `elasticsearch` 和 `milvus`。

### 9. 下一步

建议下一轮重点不再扩 Provider，而是：

1. Transactional Outbox / Index Worker
2. External index version / document version
3. 索引幂等与补偿
4. Shadow Retrieval 对比 local vs external
5. Elasticsearch 中文 analyzer / IK 或业务词典评估
6. Milvus HNSW / quantization 参数压测
7. 50k / 100k 真引擎 P50/P95/P99 对比

## V1.1 Elasticsearch + Milvus 双检索引擎迁移报告

### 目标
正式生产检索选型调整为 MySQL + Elasticsearch + Milvus + Neo4j，替换 OpenSearch + Qdrant。

### 版本
- Elasticsearch 9.5.3
- Milvus 3.0.1
版本在 2026-09-15 根据官方 Release Notes 核对。

### 代码
- `elasticsearch_provider.py`：BM25、ACL/status filter、bulk upsert、status version guard、index alias 蓝绿。
- `milvus_provider.py`：REST v2 collection/entity/search/alias，Dense Vector + scalar filter。
- `external.py`：只保留兼容导出，避免再次形成 700+ 行供应商大文件。
- `config.py`：ELASTICSEARCH_* / MILVUS_*。
- Milvus 默认 REST v2 端口 19530，认证变量 `MILVUS_TOKEN`。
- Elasticsearch analyzer 通过 `ELASTICSEARCH_ANALYZER` 配置，默认 standard；中文 analyzer 必须在真实集群安装并评测后启用。

### 数据库
新增 Flyway `V7__elasticsearch_milvus_retrieval.sql`，将 schema release 的 opensearch/qdrant 列迁移为 elasticsearch/milvus 命名。

### 一致性
保留 Transactional Outbox、aggregate indexVersion、RETRY/DEAD/replay/skip、MySQL authoritative snapshot、checksum/high-watermark、schemaVersion 蓝绿发布。

### 测试
Mock Contract 已覆盖 Elasticsearch query、Milvus REST v2 search、Outbox status contract、两端蓝绿 rebuild/activate。
新增 migration gate，禁止生产代码/配置残留 OpenSearch/Qdrant。

### 当前环境限制
当前环境没有 Docker/Maven，因此没有声称真实 Elasticsearch 9.5.3、Milvus 3.0.1、MySQL Testcontainers 或 Java build 已通过。真实 Release Qualification 必须验证 analyzer、Milvus filter/alias、collection schema、故障恢复和容量。
