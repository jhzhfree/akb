# 主机与账号权限管理规范

> 文件编号：OPS-RULE-02　|　版本：V2.4　|　生效日期：2026-05-15　|　有效期至：2027-05-14
> 归口部门：运维部（安全审计员复核）　|　审批人：王强（E10087）

## 一、账号分类与命名

生产环境账号分为四类，命名与用途如下表。所有账号**必须**绑定实名，禁止共享账号。

| 类别 | 命名规则 | 用途 | 默认有效期 |
|---|---|---|---|
| 人员账号 | 姓名拼音，如 `zhangwei` | 运维人员登录堡垒主机 | 在职期间，每季度复核 |
| 资源账号 | 服务名，如 `app` / `mysql` / `redis` | 应用与中间件运行身份 | 长期，随资源下线回收 |
| 特权账号 | `root` / `k8sops` | 紧急维护 | 仅审批后临时启用，单次 4 小时 |
| 外部账号 | `v_<厂商>_<姓名>` | 厂商支持与外包驻场 | 30 天，到期自动停用 |

## 二、权限申请与审批

1. 申请人通过 OA 提交《生产环境权限申请单》，写明**主机清单、账号类型、操作范围、有效期**；
2. 权限审批链：直属主管 → 运维值班台 → 安全审计员（涉及 root 或生产数据库时加签运维总监）；
3. 审批通过后由堡垒主机（KosBastion 4.2）自动下发，权限到期自动回收；
4. **禁止**通过工单以外的任何方式（口头、群消息、邮件）授予生产权限。

```bash
# 权限下发后在堡垒主机核对（示例：查询 zhangwei 的可登录主机与有效期）
kosbastion-cli user show zhangwei
# 输出示例
# user: zhangwei (E10231)
# hosts: srv-pay-01, srv-pay-02, srv-order-03, srv-gateway-01
# accounts: app, deploy
# expiresAt: 2026-11-14 23:59
```

## 三、外包与外部厂商账号

- 外包驻场与厂商人员**只能**使用外部账号，有效期上限 **30 天**；
- 外部账号**默认禁止**执行 L1/L2 高危命令，确需执行的须由内部人员陪同并双人复核；
- 外部人员的所有操作**强制录屏并全量留存**，留存期 180 天；
- 合作结束后 24 小时内禁用账号并导出其操作审计归档。

## 四、特权账号使用

- `root` 权限默认关闭，需通过堡垒主机「临时提权」申请，审批人为运维总监或安全审计员；
- 单次提权有效期 **4 小时**，到期自动回收，系统记录提权原因与操作序列；
- 提权期间执行的每一条命令进入高危命令实时检测通道（见 OPS-RULE-03）。

## 五、账号清理与复核

| 周期 | 动作 | 责任人 |
|---|---|---|
| 每月 | 扫描 90 天未登录账号，通知确认后停用 | 值班台 |
| 每季度 | 全量账号实名复核，回收离职人员账号 | 安全审计员 |
| 离职当天 | 立即停用账号、回收密钥、导出审计归档 | 值班台 + 安全审计员 |
| 资源下线 | 同步回收该资源上的全部资源账号 | SRE |

## 六、违规处理

- 共享账号、借用他人账号：一级违规，暂停权限 30 天并通报；
- 私自增设账号或绕过堡垒主机直连生产：一级违规，按《员工奖惩管理办法》处理；
- 权限过期未及时回收造成敞口的，追究审批人与资源负责人责任。

## 七、配套系统

本规范通过堡垒主机 KosBastion 4.2 强制执行，审计数据同步至日志审计平台 KosAudit，数据库操作另由 DB-Audit 独立留存。三个系统的账号主体必须一致，差异以本规范为准。
