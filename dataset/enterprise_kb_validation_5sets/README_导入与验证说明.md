# 企业知识库五类验证数据集

本数据集全部为**合成模拟数据**，不包含真实企业内部资料。共 5 个知识库、20 份 DOCX。

## 导入方法
1. 在系统创建五个同名知识库。
2. 分别上传对应目录内的四份 DOCX，保留文档版本和原始文件名。
3. 运行清洗、抽取、裁决、卡片生成、图谱构建和索引。
4. 对照 `validation_cases.csv` 进行检索和问答测试。

## 重点验证
- 制度库：V1/V2采购门槛冲突，按生效日期裁决。
- 人员关系库：组织/项目/岗位跨文档实体关联及ACL。
- 漏洞库：公告→资产→修复→复测的证据链。
- 运维库：告警→定位→变更→回滚流程。
- 综合库：跨领域召回和引用溯源。

## 重要说明
文件中的指标、资产、人员、漏洞编号均为测试设定，不能作为真实运维或合规决策依据。
