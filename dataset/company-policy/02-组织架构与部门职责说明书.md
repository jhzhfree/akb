# 组织架构与部门职责说明书

> 文件编号：HR-ORG-02　|　版本：V3.0　|　生效日期：2026-03-01　|　归口部门：人力资源部
> 审批：总经理办公室　|　最近修订：2026-08-15（研发中心拆分平台工程部）

## 一、公司组织架构

```text
总经理办公室
├─ 产品中心
│  ├─ 产品部（支付产品线、订单产品线、数据产品线）
│  └─ 用户体验部（交互设计、用户研究）
├─ 研发中心
│  ├─ 平台工程部（基础架构、中间件、运维 SRE）
│  ├─ 支付研发部（支付网关、清结算、风控）
│  ├─ 订单研发部（订单、履约、库存）
│  └─ 质量与测试部（功能测试、自动化测试、压测）
├─ 运维部（SRE 组、DBA 组、中间件组、值班台）
├─ 市场与销售中心（直销、渠道、解决方案）
├─ 客户成功部（交付、实施、支持）
├─ 职能中心
│  ├─ 人力资源部
│  ├─ 财务部
│  ├─ 法务与合规部
│  ├─ 行政部
│  └─ 信息安全部
└─ 内部审计部（直接向总经理汇报）
```

## 二、部门职责

| 部门 | 核心职责 | 关键交付 | 负责人 |
|---|---|---|---|
| 产品中心 | 产品规划、需求管理、版本定义 | PRD、路线图、版本计划 | 周敏（P9） |

| 支付研发部 | 支付网关、清结算、风控规则 | 支付链路可用率 ≥ 99.9% | 赵鹏（P8） |
| 订单研发部 | 订单、履约、库存与对账 | 订单一致性与履约时效 | 吴桐（P8） |
| 运维部 | 生产环境稳定性、变更、应急响应 | 可用率、MTTR、变更成功率 | 王强（P9） |
| 客户成功部 | 交付实施、技术支持、客户满意度 | 交付验收率、NPS | 何静（P8） |
| 人力资源部 | 招聘、薪酬绩效、培训、员工关系 | 编制达成率、人均效能 | 林岚（P9） |
| 财务部 | 核算、资金、税务、预算与费用 | 月度结账、预算执行率 | 郑楠（P9） |
| 法务与合规部 | 合同审核、合规、知识产权、数据合规 | 合同审核时效、合规事件数 | 苏杭（P8） |
| 信息安全部 | 安全策略、漏洞治理、权限与审计 | 安全事件数、漏洞修复时效 | 陈静（P8，兼安全审计） |

## 四、跨部门协作机制

| 事项 | 主导部门 | 参与部门 | 机制 |
|---|---|---|---|
| 版本发布 | 产品中心 | 研发、测试、运维 | 双周迭代 + 发布评审会 |
| 生产故障 | 运维部 | 研发、产品、客户成功 | 按《应急预案与故障升级流程》 |
| 数据合规 | 信息安全部 | 法务、研发、运维 | 季度合规评审 |
| 采购与合同 | 财务部 | 法务、需求部门 | 采购审批流（HR-FIN-10） |
| 人员编制 | 人力资源部 | 总经理办公室、各部门 | 年度编制规划 |

## 五、汇报关系与授权

- 部门负责人向总经理（或分管副总）汇报；
- 单笔支出授权：部门负责人 ≤ 5 万，分管副总 ≤ 50 万，总经理 > 50 万；
- 生产变更授权：常规变更由值班台 + 主管审批，重大变更需运维总监 + 业务负责人（见运维规范 OPS-RULE-08）；
- 人事任免：P7 及以下由分管副总决定，P8 及以上由总经理办公会决定。

## 六、2026 年组织调整说明

2026-08-15 起研发中心新增**平台工程部**，原属支付研发部的「基础架构组」与运维部的「工具链组」划入该部门，旨在统一技术底座。人员与系统归属变更不影响本说明书其他条款。
