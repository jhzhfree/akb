# 入职、离职与工作交接管理办法

> 文件编号：HR-POL-12　|　版本：V2.4　|　生效日期：2026-01-01　|　有效期至：2026-12-31
> 归口部门：人力资源部　|　会签：行政部、信息安全部、财务部

## 一、入职流程

```text
Offer 发放 → 背景调查（P7 及以上或财务/数据岗位）→ 入职材料提交
→ 入职当天：合同签订、账号开通、设备领用、入职引导
→ 首周：部门介绍、导师分配、系统权限申请
→ 首月：入职培训（文化、制度、安全、系统）→ 试用期目标设定
```

### 1.1 入职材料清单

| 材料 | 说明 |
|---|---|
| 身份证原件与复印件 | 核验身份 |
| 学历/学位证明 | 学信网验证报告 |
| 离职证明 | 上家单位出具 |
| 体检报告 | 近 3 个月内 |
| 银行卡 | 工资卡（指定银行） |
| 竞业协议 | 核心岗位签署 |

### 1.2 入职当天开通项

| 项目 | 负责部门 | 时限 |
|---|---|---|
| 企业邮箱与 SSO 账号 | 信息安全部 | 当天 |
| 办公终端与门禁 | 行政部 | 当天 |
| 业务系统权限（按岗位模板） | 用人部门 + 信息安全部 | 2 个工作日内 |
| 生产权限（如需要） | 运维值班台审批 | 3 个工作日内 |

## 二、试用期管理

| 节点 | 动作 | 责任人 |
|---|---|---|
| 第 1 周 | 试用期目标设定（3–5 条） | 主管 |
| 第 1 个月 | 入职培训完成（16 学时） | HR |
| 第 3 个月 | 中期评估，反馈改进点 | 主管 |
| 第 6 个月 | 转正答辩（述职 + 评审） | 主管 + HR + 评委 |
| 转正前 10 日 | 提交转正申请与自评 | 员工 |

转正条件：考核 ≥ B（良好）且无违纪记录；未通过的，可延长试用期一次（不超过原期限）或终止试用。

## 三、离职流程

| 类型 | 通知期 | 说明 |
|---|---|---|
| 主动离职（正式） | 提前 30 日书面通知 | 试用期提前 3 日 |
| 协商解除 | 双方约定 | 签署解除协议 |
| 合同到期不续 | 提前 30 日通知 | — |
| 公司解除 | 依法支付经济补偿 | 需 HR 与法务审核 |

### 3.1 离职交接清单

| 类别 | 交接内容 | 接收人 | 确认 |
|---|---|---|---|
| 工作事项 | 在办事项、进度、风险与下一步 | 主管指定 | 书面 |
| 文档资产 | 设计文档、运维手册、复盘报告（上传知识库） | 接任者 | 知识库链接 |
| 代码与配置 | 分支合并、配置说明、密钥交接 | 技术负责人 | Git 记录 |
| 系统权限 | 生产账号、堡垒主机、监控平台回收 | 信息安全部 | 回收单 |
| 硬件资产 | 笔记本、显示器、门禁卡、令牌 | 行政部 | 资产单 |
| 财务事项 | 借款、报销、备用金结清 | 财务部 | 结算单 |
| 客户与外部关系 | 对接人、在谈项目、合同状态 | 主管 | 移交说明 |

### 3.2 账号与权限回收

- 离职当日：**禁用** SSO、邮箱、企业微信、VPN、堡垒主机账号；
- 3 个工作日内：删除或转移文件所有权、回收密钥与 API 凭证、退出相关项目组；
- 生产权限：由信息安全部在离职当日回收，回收记录留存 1 年；
- 外包与厂商人员：合作结束 24 小时内禁用账号并导出操作审计归档。

## 四、离职结算

| 项目 | 规则 |
|---|---|
| 工资 | 按实际出勤日结算，次月发薪日发放 |
| 年假未休 | 按 3 倍日薪折算（月薪 / 21.75 × 天数 × 3） |
| 调休未休 | 按 1 倍日薪折算 |
| 借款/赔偿 | 从结算金额中扣除 |
| 竞业限制 | 按协议支付补偿（月工资 30%），最长 24 个月 |
| 离职证明 | 离职后 5 个工作日内出具 |

## 五、知识资产保留

- 离职前须将个人文档、设计方案、排障笔记上传至公司知识库（Confluence 空间或知识平台），**不得删除或带走**；
- 代码须合并至主干或指定分支，禁止删除仓库与分支；
- 未交接文档导致知识缺失的，主管在离职单上标注，影响团队知识资产考核。

## 六、返聘

- 离职满 6 个月且离职原因为个人原因、绩效 B 及以上者，可申请返聘；
- 返聘需原部门或新部门发起，HR 与分管副总审批；
- 返聘司龄重新计算，职级按能力评估确定。
