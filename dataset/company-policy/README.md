# 场景数据集 2 · 公司制度知识库

> 场景定位：面向全员的企业制度知识库，覆盖**员工手册 + 考勤休假 + 薪酬福利 + 报销差旅 + 绩效晋升 + 培训发展 + 信息安全 + 采购合同 + 奖惩 + 入职离职 + IT 资产 + FAQ + 修订通知**，模拟一家 1,280 人公司的制度体系。
> 虚构主体：蓝湖科技，与「运维知识库」「工程协同」共用同一主体与工号体系。

## 一、数据集构成

| 编号 | 文件 | 知识类型（Schema） | 主要内容 | 典型问题 |
|---|---|---|---|---|
| 01 | 员工手册 · 总则与行为规范 | EMPLOYEE_HANDBOOK | 价值观、入职、工时、行为红线 | 试用期多久？ |
| 02 | 组织架构与部门职责说明书 | POLICY_RULE | 组织架构、部门职责、岗位与协作机制 | 支付研发部归谁管？ |
| 03 | 考勤与休假管理办法 | POLICY_RULE | 工时、假期额度、加班调休、扣薪规则 | 年假有几天？病假要证明吗？ |
| 04 | 薪酬与福利管理办法 | POLICY_RULE | 薪酬结构、职级带宽、五险一金、福利清单 | 公积金比例是多少？ |
| 05 | 差旅与费用报销管理办法 | POLICY_RULE | 出差审批、交通住宿标准、报销时效 | 一线城市住宿标准多少？ |
| 06 | 绩效管理办法 | POLICY_RULE | 周期、等级分布、OKR/KPI、结果应用 | 绩效 C 会怎样？ |
| 07 | 职级与晋升管理办法 | POLICY_RULE | P/M 双通道、晋升条件、评审流程、调薪 | 晋升一年几次？ |
| 08 | 培训与人才发展管理办法 | POLICY_RULE | 培训体系、学时、学习基金、导师制、HiPo | 年度学时不够会怎样？ |
| 09 | 信息安全与数据合规管理办法 | POLICY_RULE | 数据分级、访问控制、外发、事件分级 | 能把客户数据拷到本地吗？ |
| 10 | 采购与合同管理制度 | POLICY_RULE | 采购分类、审批权限、供应商管理、合同管理 | 50 万采购谁审批？ |
| 11 | 员工奖惩管理办法 | POLICY_RULE | 奖励类别、违规三级、处分流程、赔偿 | 共享账号算几级违规？ |
| 12 | 入职离职与交接管理办法 | POLICY_RULE | 入职流程、试用期、离职交接、结算 | 离职要交接什么？ |
| 13 | 办公与 IT 资产管理制度 | POLICY_RULE | 资产分类、配置标准、领用归还、盘点报废 | 笔记本几年更换？ |
| 14 | 员工常见问题 FAQ | POLICY_FAQ | 30 问，含冲突口径说明 | 年假到底多少天？ |
| 15 | 制度修订通知 · 9 月休假与报销调整 | POLICY_NOTICE | 新旧口径对照、过渡期、失效条件 | 报销时限是 30 天还是 60 天？ |

**体量**：15 篇 / 约 3.4 万字，含 45+ 张表格，覆盖 12 个制度域、30+ 个额度与天数口径、6 个部门、8 个职级。

## 二、刻意设计的「真实场景特征」

| 特征 | 设计 | 用途 |
|---|---|---|
| 双口径冲突 | 03/05 与 15 在年假额度（5→10 天）、病假证明（3→2 天）、报销时效（30→60 日）、住宿标准（600→700 元）四处不一致 | 验证「以生效日期较晚者为准」的冲突裁决 |
| 交叉引用 | 14 的 FAQ 明确标注「以通知为准」，与 03/05 形成互指 | 验证答案是否给出双口径与依据 |
| 密级差异 | 04（内部）、09（合规要求）、11（奖惩）密级不同 | 验证权限标签与权威分 |
| 主体互通 | 工号 E10231 等在三个场景中一致 | 验证跨知识库实体关联 |
| 数字密集 | 天数、金额、比例、带宽均为结构化数字 | 验证 FACT 类问题与表格抽取 |

## 四、检索策略（已创建）

「公司制度」策略要点：卡片 1.30、断言 1.25（条款与时效口径优先）；冲突类优先级 96（最高）；权威权重 0.25、时效 0.20（修订通知最优先）；`minChunkEvidence=3`；拒答文案引导咨询 HRBP。定义文件：`../_scenarios/company-policy.profile.json`。

## 五、导入与验证

```bash
python3 scripts/build-scenario-kbs.py --scenario policy --token <token>
```

验证建议：

1. `年假有多少天` → 应同时给出 03 的旧口径与 15 的新口径（10 天），并说明 2026-09-01 起生效；
2. `一线城市住宿标准和报销时限` → 应给出 700 元/晚与 60 日，并标注与 05 的差异；
3. `连续两个季度绩效 C 怎么办` → 应命中 06 与 11，说明 PIP 与岗位评估；
4. `外包人员能申请 root 提权吗` → 应命中 02/09/11，明确禁止并给出替代方案。
