# 采购与合同管理制度

> 文件编号：FIN-POL-10　|　版本：V2.6　|　生效日期：2026-01-01　|　有效期至：2026-12-31
> 归口部门：财务部（采购组）　|　会签：法务与合规部　|　审批：总经理办公室

## 一、采购分类与审批权限

| 采购类型 | 金额区间 | 审批链 | 采购方式 |
|---|---|---|---|
| 零星采购 | < 1 万元 | 部门负责人 | 直接采购 |
| 一般采购 | 1 万–5 万元 | 部门负责人 + 财务 | 询价比价（≥ 2 家） |
| 较大采购 | 5 万–50 万元 | 分管副总 + 财务 + 法务 | 比价或招标（≥ 3 家） |
| 重大采购 | > 50 万元 | 总经理办公会 | 公开招标 + 评标委员会 |

## 二、采购流程

```text
需求提出（部门填写采购申请单，含预算与理由）
→ 预算核对（财务确认预算科目与余额）
→ 供应商选择（合格供应商库 / 新供应商准入评审）
→ 询价比价或招标（留存报价与评标记录）
→ 合同起草与法务审核（3 个工作日内）
→ 审批（按金额权限）
→ 签署与盖章（合同专用章）
→ 验收与付款（按合同节点）
→ 归档（合同原件 + 验收单 + 发票）
```

## 三、供应商管理

| 环节 | 要求 |
|---|---|
| 准入 | 营业执照、资质证明、财务与信用状况、案例与口碑、保密协议 |
| 评估 | 每年一次：交付质量、响应时效、价格水平、合规性 |
| 分级 | A（优秀，优先合作）、B（合格）、C（观察，限期整改）、D（淘汰） |
| 黑名单 | 存在商业贿赂、重大违约、数据安全事故的供应商列入黑名单，3 年内不得合作 |

## 四、合同管理

### 4.1 合同类型与要素

| 类型 | 关键条款 |
|---|---|
| 采购合同 | 标的、价格、交付期限、验收标准、质保、违约责任 |
| 技术服务合同 | 服务范围、SLA、人员资质、知识产权归属、保密 |
| 软件许可 | 授权范围、期限、用户数、升级与维保、禁止反向工程 |
| 保密协议（NDA） | 保密范围、期限、违约责任 |
| 数据处理协议 | 数据范围、用途、安全措施、删除与返还、审计权 |

### 4.2 审核要点

法务审核关注：主体资格、权利义务对等、付款与验收节点、知识产权归属、保密条款、违约责任、争议解决与管辖、数据合规条款。

### 4.3 签署与用章

- 合同须由法定代表人或授权代表签署，授权须有书面授权书；
- 用章走 OA 用章申请，合同专用章由行政部保管，用章须附审批完成的合同；
- 禁止先履行后签合同（特殊情况需分管副总书面特批）。

## 五、付款与验收

| 节点 | 付款比例（参考） | 条件 |
|---|---|---|
| 预付款 | 0%–30% | 重大采购且供应商要求，需担保 |
| 到货/交付 | 40%–60% | 验收合格并签署验收单 |
| 质保金 | 5%–10% | 质保期（通常 12 个月）满后支付 |
| 尾款 | 剩余 | 服务完成或项目结项 |

付款申请须附：采购申请单、合同、验收单、发票（增值税专用发票优先）。

## 六、常见违规

1. 化整为零规避审批权限；
2. 未比价直接指定供应商；
3. 先履行后签合同；
4. 收受供应商回扣或礼品（按《员工奖惩管理办法》一级违规处理）；
5. 验收流于形式，导致交付质量不达标。

## 七、与运维相关的采购

生产环境相关的硬件、云服务、安全产品采购，需运维部与信息安全部参与技术评审，验收由运维部出具技术验收意见。涉及客户数据处理的供应商须签署数据处理协议并接受年度安全评估。
